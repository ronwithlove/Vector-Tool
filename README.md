# Vector Tool

把 Logo、插画类位图转成**干净、少碎片、好编辑**的 SVG。纯算法，本地运行，没有按次成本。

## 启动

macOS：双击 `start.command`（第一次会自动安装依赖）。

或者命令行：

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python server.py          # 自动打开 http://127.0.0.1:8765
```

命令行批处理：`.venv/bin/python cli.py 图片.png -o 输出.svg --params '{"max_colors": 6}'`

## 处理流程

| 步骤 | 做什么 | 解决什么问题 |
|---|---|---|
| 1. 工作尺寸 | 小图先放大到约 1600px | 小符号（如 ®）有足够像素来描 |
| 2. 降噪 | 中值 + 双边滤波；再用亮度引导修正色度 | 纸纹、JPEG 压缩色差、4:2:0 色度块造成的波浪边 |
| 3. 取主色 | 找 Lab 颜色直方图的峰值，色差 ΔE 小于阈值的强制合并 | 同一米色被拆成几种相近色 |
| 4. 清碎片 | 去抗锯齿细条、去“混出来的”过渡色、小块并入周围 | 边缘一圈细碎色带、零星小块 |
| 5. 叠放 | 大色块在下、小色块在上，下层向上层外扩 | 色块之间没有缝，路径更少（设计师手绘习惯） |
| 6. 拟合 | 亚像素轮廓 → 沿轮廓平滑 → 找尖角并还原 → 直线 / 贝塞尔 / 正圆椭圆 | 节点少、边缘圆滑、尖角是尖的 |
| 7. 规整 | 接近水平/垂直的直线吸附；接近正圆的变正圆；小形状按比例放宽 | ® 里的 R 横平竖直、圆是正圆 |

## 代码结构

```
server.py              本地网页服务（只用标准库）
cli.py                 命令行
vectortool/pipeline.py 读图、降噪、取色、清碎片
vectortool/trace.py    叠放分层、轮廓、尖角、规整、输出 SVG
vectortool/fit.py      直线检测、贝塞尔拟合、椭圆识别
web/                   界面
samples/               测试图
```
